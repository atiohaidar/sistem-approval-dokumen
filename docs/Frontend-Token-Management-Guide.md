# Frontend Token Management Guide

## Overview

This guide describes the frontend implementation for secure document token management, completing the full-stack secure access system.

## Components

### 1. Secure Access Page (`/secure/[token]`)

**Purpose**: Allow external users to access documents via secure token without authentication.

**Location**: `frontend/pages/secure/[token].vue`

**Features**:
- Token validation on page load
- Document information display
- PDF preview (iframe)
- Approval progress tracking
- Token expiration warning
- Security information notice

**User Flow**:
1. User clicks shared link (e.g., `https://app.com/secure/abc123...`)
2. Page validates token with backend API
3. If valid: Show document preview and info
4. If invalid: Show error message with option to return home

**States**:
- Loading: Spinner with "Memverifikasi akses..." message
- Error: Red alert with error message
- Success: Document preview with full information

### 2. Token Management Composable (`useDocumentTokens`)

**Purpose**: Reusable logic for token operations across components.

**Location**: `frontend/composables/useDocumentTokens.ts`

**Functions**:

#### `generateToken(documentId, params)`
Generate a new access token for a document.

```typescript
const { generateToken } = useDocumentTokens()

const result = await generateToken(documentId, {
  expires_in_hours: 48,
  purpose: "External reviewer access",
  generated_for: "john@example.com"
})

// Returns: { token_id, access_url, expires_at }
```

#### `fetchTokens(documentId)`
Get all active tokens for a document.

```typescript
const { tokens, fetchTokens } = useDocumentTokens()

await fetchTokens(documentId)
// tokens.value will contain array of active tokens
```

#### `revokeToken(documentId, tokenId, reason)`
Revoke a specific token.

```typescript
const { revokeToken } = useDocumentTokens()

const success = await revokeToken(documentId, tokenId, "Security concern")
// Returns: boolean
```

#### `rotateToken(documentId, tokenId, expiresInHours)`
Generate new token and automatically revoke the old one.

```typescript
const { rotateToken } = useDocumentTokens()

const result = await rotateToken(documentId, tokenId, 72)
// Returns: { token_id, access_url, expires_at }
```

#### `fetchAccessLogs(documentId, hours)`
Get access logs and statistics.

```typescript
const { accessLogs, accessStats, fetchAccessLogs } = useDocumentTokens()

await fetchAccessLogs(documentId, 24)
// accessStats.value contains statistics
// accessLogs.value contains log entries
```

#### `copyTokenUrl(url)`
Copy URL to clipboard with fallback.

```typescript
const { copyTokenUrl } = useDocumentTokens()

const success = await copyTokenUrl(tokenUrl)
// Returns: boolean
```

#### `formatExpiresIn(expiresAt)`
Format expiration as relative time.

```typescript
const { formatExpiresIn } = useDocumentTokens()

const text = formatExpiresIn("2025-11-25T10:00:00Z")
// Returns: "5 hari lagi" or "3 jam lagi" or "Kedaluwarsa"
```

**Reactive State**:
- `tokens`: Array of active tokens
- `accessLogs`: Array of access log entries
- `accessStats`: Statistics object
- `loading`: Boolean loading state
- `error`: String error message (null if no error)

### 4. Document Detail Integration

**Purpose**: Add token management section to document detail page.

**Location**: Modified `frontend/pages/documents/[id].vue`

**Changes Made**:

#### Added Token Manager Section
```vue
<!-- Token Management Section -->
<div v-if="canManageTokens" class="card">
  <DocumentTokenManager :document-id="doc.id" />
</div>
```

#### Added Permission Check
```typescript
const canManageTokens = computed(() => {
  if (!doc.value || !authStore.user) return false
  
  // Creator can manage tokens
  if (doc.value.created_by === authStore.user.id) return true
  
  // Admin can manage tokens
  if (authStore.user.role === 'admin') return true
  
  // Approvers can manage tokens
  if (doc.value.approvers) {
    for (const level of doc.value.approvers) {
      if (Array.isArray(level) && level.includes(authStore.user.id)) {
        return true
      }
    }
  }
  
  return false
})
```

**Authorization Rules**:
1. Document creator can manage tokens
2. Admin users can manage tokens
3. Assigned approvers (any level) can manage tokens
4. Other users cannot see token management section

## User Workflows

### Workflow 1: Share Document with External Reviewer

1. **Creator uploads document** → Document gets auto-generated QR token
2. **Creator wants to share manually** → Goes to document detail page
3. **Sees "Token Akses" section** → Clicks "Buat Token Baru"
4. **Fills modal**:
   - Purpose: "For external legal review"
   - Expiration: 72 hours
5. **Clicks "Buat Token"** → Token generated
6. **Modal shows token URL** → Clicks copy button
7. **Shares URL via email/chat** → Reviewer receives link
8. **Reviewer clicks link** → Opens `/secure/[token]` page
9. **Reviewer sees document** → Can preview and download
10. **Token expires after 72 hours** → Access automatically revoked

### Workflow 2: Rotate Token for Security

1. **Admin notices suspicious activity** → Goes to document detail
2. **Sees active token list** → Identifies problematic token
3. **Clicks rotate button** (🔄) → Confirmation dialog appears
4. **Confirms rotation** → New token generated, old revoked
5. **New URL displayed** → Admin shares new URL
6. **Old URL immediately invalid** → Previous links stop working

### Workflow 3: Revoke Access

1. **Creator completes collaboration** → No longer needs external access
2. **Opens document detail** → Views active tokens
3. **Clicks revoke button** (🗑️) → Confirmation dialog
4. **Confirms revocation** → Token invalidated
5. **Success message shown** → Token removed from list
6. **Any attempts to use URL** → Shows "Access Denied" error

## API Integration

All frontend components use the backend API endpoints:

| Frontend Function | Backend Endpoint | Method |
|------------------|------------------|--------|
| `generateToken()` | `/api/documents/{id}/access-tokens` | POST |
| `fetchTokens()` | `/api/documents/{id}/access-tokens` | GET |
| `revokeToken()` | `/api/documents/{id}/access-tokens/{tokenId}/revoke` | POST |
| `rotateToken()` | `/api/documents/{id}/access-tokens/{tokenId}/rotate` | POST |
| `fetchAccessLogs()` | `/api/documents/{id}/access-logs` | GET |
| Secure Access Page | `/api/secure/documents/{token}` | GET |
| PDF Preview | `/api/secure/documents/{token}/preview` | GET |
| PDF Download | `/api/secure/documents/{token}/download` | GET |

## Error Handling

### Network Errors
- Composable catches fetch errors
- Sets `error` reactive state
- Component displays error message
- User can retry operation

### Validation Errors
- Backend returns 422 with validation messages
- Composable extracts error message
- Component shows specific error
- User can correct and retry

### Authorization Errors
- Backend returns 403 Forbidden
- Composable handles gracefully
- Component shows "Unauthorized" message
- User redirected or shown alternative

### Token Errors
- Invalid token: "Token akses tidak valid atau telah kedaluwarsa"
- Expired token: Same message with expired indicator
- Revoked token: Same message
- All logged for security monitoring

## Security Considerations

### Frontend Security
1. **No Token Storage**: Tokens not stored in localStorage/sessionStorage
2. **No Token Display**: Only URLs shown, never raw token values
3. **Authorization Checks**: Permission checks before showing UI
4. **HTTPS Only**: All API calls use secure connection
5. **CSRF Protection**: Sanctum CSRF tokens included

### User Education
1. **Expiration Warnings**: Clear display of when token expires
2. **Security Notices**: Information boxes about secure access
3. **Confirmation Dialogs**: Prevent accidental revocations
4. **Purpose Field**: Encourages documentation of token use

## Troubleshooting

### Token Manager Not Visible
**Problem**: Token management section doesn't appear.
**Solution**: Check user permissions. Only creator, admin, or approvers can see it.

### Cannot Copy URL
**Problem**: Copy button doesn't work.
**Solution**: Check browser permissions for clipboard access. Fallback will trigger automatically.

### PDF Preview Not Loading
**Problem**: Iframe shows blank or error.
**Solution**: Check CORS settings, ensure backend allows iframe embedding.

### Token List Empty
**Problem**: No tokens shown despite generation.
**Solution**: Check API response, verify tokens not expired, check network tab for errors.

### Secure Page Shows Error
**Problem**: Valid token shows "Access Denied".
**Solution**: Check token expiration, verify backend API is accessible, check browser console for errors.
